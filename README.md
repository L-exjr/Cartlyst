# SwiftMart

SwiftMart is a modern e-commerce mobile application built with React Native and Expo, offering a seamless shopping experience for users.

## Features

- Modern and intuitive user interface
- Secure user authentication
- Product browsing and search
- Shopping cart functionality
- Order management
- Image handling capabilities
- Cross-platform compatibility (iOS and Android)

## Prerequisites

Before you begin, ensure you have the following installed:

- Node.js (Latest LTS version recommended)
- npm or yarn
- Expo CLI (`npm install -g expo-cli`)
- iOS Simulator (for Mac users) or Android Studio (for Android development)

## Installation

1. Clone the repository:

```bash
git clone https://github.com/yourusername/swiftmart.git
cd swiftmart
```

2. Install dependencies:

```bash
npm install
# or
yarn install
```

3. Start the development server:

```bash
npm start
# or
yarn start
```

## Available Scripts

- `npm start` or `yarn start` - Starts the Expo development server
- `npm run ios` or `yarn ios` - Runs the app on iOS simulator
- `npm run android` or `yarn android` - Runs the app on Android emulator
- `npm run web` or `yarn web` - Runs the app in web browser

## Tech Stack

- React Native
- Expo
- Expo Router for navigation
- Zustand for state management
- Expo Secure Store for secure data storage
- Expo Image Picker for image handling
